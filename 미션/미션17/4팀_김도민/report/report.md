# 미션 17 보고서 초안

## 1. 프로젝트 개요

이번 프로젝트는 사용자가 웹 브라우저에서 손글씨 숫자를 그리면 MNIST ONNX 모델을 이용해 해당 숫자를 예측하는 Streamlit 기반 AI 서비스입니다. 모델을 새로 학습하는 것이 아니라, 준비된 ONNX 모델을 실제 서비스 화면에 연결하고 Docker로 배포 가능한 형태로 만드는 것이 목표입니다.

## 2. 서비스 화면 구성

서비스 화면은 입력 캔버스, 전처리 이미지, 모델 추론 결과, 이미지 저장소로 구성했습니다. 입력 캔버스에서는 사용자가 마우스로 숫자를 그리고, 전처리 이미지 영역에서는 모델 입력에 맞게 변환된 28x28 흑백 이미지를 확인할 수 있습니다. 모델 추론 결과 영역에서는 최종 예측 숫자와 0부터 9까지의 예측 확률을 막대 차트로 표시합니다. 이미지 저장소에는 추론에 사용된 이미지와 예측 결과가 저장됩니다.

## 3. 모델과 추론 흐름

MNIST CNN ONNX 모델을 `models/mnist_cnn.onnx` 경로에 두고 ONNX Runtime으로 로드했습니다. Streamlit의 캐싱 기능을 사용하여 모델 세션을 한 번만 생성하고 재사용하도록 구성했습니다.

사용자가 그린 캔버스 이미지는 흑백 이미지로 변환한 뒤, 숫자 영역을 중심으로 잘라 28x28 크기로 조정했습니다. 이후 픽셀 값을 0부터 1 사이의 float32 값으로 정규화하고, 모델 입력 shape인 `(1, 1, 28, 28)`에 맞춰 추론을 수행했습니다.

## 4. 코드 설명

- `app.py`: Streamlit 화면 구성, 캔버스 입력, 모델 추론, 결과 표시, 이미지 저장소 표시
- `image_processing.py`: 빈 캔버스 확인, 이미지 전처리, 전처리 이미지 저장
- `inference_utils.py`: ONNX 모델 세션 생성, logits를 확률로 변환, 최종 예측 label 계산
- `tests/`: 이미지 전처리와 추론 결과 해석 로직 검증
- `Dockerfile`: Streamlit 서비스를 Docker 이미지로 실행하기 위한 설정

## 6. 디버깅과 해결 과정

| 항목 | 내용 |
| --- | --- |
| 오류 상황 | 전처리 없이 캔버스 이미지를 그대로 모델에 넣으면 모델 입력 shape와 맞지 않을 수 있음 |
| 원인 추정 | 캔버스 이미지는 RGBA 형태이고, MNIST 모델은 `(1, 1, 28, 28)` float32 입력을 기대함 |
| 해결 방법 | `image_processing.py`에서 흑백 변환, 색상 반전, 중심 crop, 28x28 resize, 정규화, shape 변환을 수행함 |
| 확인 결과 | 자동 테스트에서 전처리 결과 shape, dtype, 값 범위, preview 이미지 크기를 검증함 |
